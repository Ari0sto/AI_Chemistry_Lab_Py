# Отчёт — AI Chemistry Lab

## Цель

Разработать локальное веб-приложение на Python и React/TypeScript для прогнозирования водной растворимости химических веществ на основании SMILES, применяя модель ИИ из Hugging Face.

## Модель и выбор

**Название:** `khanfs/ChemSolubilityBERTa`  
**Ссылка:** https://huggingface.co/khanfs/ChemSolubilityBERTa  
**Автор:** Farooq Khan (2024). Лицензия MIT.

Модель использует архитектуру ChemBERTa / RoBERTa и обучалась прогнозировать водную растворимость на основе набора ESOL (1128 веществ). Вход: SMILES. Выход: одно число — оценка `logS = log10(S [моль/л])`. Выбрана, поскольку принимает удобное текстовое представление молекулы, имеет пример загрузки через Transformers и работает локально.

## Алгоритм

1. Пользователь вводит название и SMILES в React.
2. FastAPI принимает запрос и вызывает RDKit (`Chem.MolFromSmiles`).
3. RDKit валидирует структуру, вычисляет формулу, нормализует SMILES.
4. Токенизатор превращает SMILES в токены.
5. ChemSolubilityBERTa вычисляет регрессионный прогноз `logS`.
6. Результат сохраняется в `data/chemistry_results.csv` и отображается в браузере.

|---|---|---|---:|

## Дополнительные возможности

- React + TypeScript графический интерфейс.
- Поиск по названию и SMILES, сортировка по `logS`.
- Сравнение любых 2+ молекул в диаграмме Recharts.
- Пакетная обработка образцов, до 30 веществ за запрос.
- Ручное добавление экспериментального значения и источника; сравнение с прогнозом по абсолютной ошибке.
- Скачивание CSV, обновление и удаление записей, обработка ошибок.

## Оценка полезности модели

Модель подходит для демонстрации возможностей ML в cheminformatics, автоматизации расчёта и сравнительного изучения структур. Однако это экспериментальная модель, не гарантирующая высокую точность на веществах вне обучающего набора. Нельзя заменять этим прогнозом лабораторные измерения, безопасность токсикологических исследований или регулируемые химические расчёты. Особенно осторожно нужно интерпретировать значения для жидкостей, полностью смешивающихся с водой: привычная экспериментальная растворимость в этих случаях не всегда описывается тем же ограниченным понятием насыщения, что для малорастворимых веществ.

## Проверка выполнения задания

При локальном пользовательском тестировании успешно выполнено 12 проверок без обнаруженных ошибок: одиночный и пакетный анализ; сохранение при перезапуске; поиск; сортировка; сравнение; ввод экспериментальных значений; экспорт и удаление; обработка ошибочных SMILES, пустых полей и недоступного backend.

Пакетная обработка 12 образцов выполнена успешно, программа подтвердила сохранение данных в `chemistry_results.csv`. **Реальные числовые результаты всех 12 образцов содержатся в локальном CSV пользователя** — их необходимо приложить к сдаваемому проекту. В данном отчёте не приводятся непроверенные значения.

## Анализ качества результатов

По трём первоначальным веществам прогнозы составили: этанол −1.0892, уксусная кислота −0.3915, бензен −1.7974 logS. Это результаты исполнения модели, а не экспериментальные измерения. Для оценки точности требуется сравнивать с данными, выраженными в той же единице, при сопоставимых температуре, условиях и определении растворимости.

Наблюдение: отрицательные прогнозы logS для этанола и уксусной кислоты не следует автоматически принимать за физически достоверную растворимость, поскольку эти жидкости смешиваются с водой и обычные справочные данные о взаимной растворимости могут иметь другую интерпретацию. У модели есть ограничения области применения и возможны существенные отклонения.

## Заключение

ИИ полезен для быстрой ориентировочной оценки свойств по SMILES и массовой предварительной обработки соединений. В данной работе автоматизированы валидация структур, получение прогнозов, визуализация и хранение результатов. Прогнозы модели не заменяют лабораторные измерения и не должны применяться как единственное основание для химических решений.
